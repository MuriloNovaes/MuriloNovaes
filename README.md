## 🚀 Sobre mim

Sou **Analytics Engineer Jr. na CrediPronto (Itaú)** e estudante de Ciência da Computação. Atuo na interseção entre **Analytics, Engenharia de Dados e Inteligência Artificial**, construindo soluções orientadas a dados e automação de processos de negócio.

Comecei como **Data Analyst Intern** e, em pouco mais de um ano, passei a atuar de ponta a ponta: de pipelines no Databricks até **agentes de IA** que integram LLMs a dados estruturados, documentos e regras de negócio.
